User Action	API Create Repository	POST /user/repos List Files	GET /repos/{owner}/{repo}/contents Create File	PUT /repos/{owner}/{repo}/contents/{path} Update File	PUT /repos/{owner}/{repo}/contents/{path} (with SHA) Delete File	DELETE /repos/{owner}/{repo}/contents/{path} Create Branch	Git References API Commit	Handled by the Create/Update File API, or Git Data API for multi-file commits  For a simple Markdown authoring experience, the Create/Update Contents API is enough because it creates the commit automatically.
