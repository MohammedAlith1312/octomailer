# 🚀 Faaz Technology Solutions — Documentation

Welcome to the official documentation for the **Faaz Technology Dashboard** — a secure, modern, and scalable web application built with Next.js 15.

---

## What is This Project?

The Faaz Technology Dashboard is a full-stack web application that provides:

- 🔒 **Secure Authentication** — Cookie-based session management with middleware route protection.
- 📊 **User Management** — A searchable, filterable user database view.
- ⚡ **Modern Stack** — Powered by Next.js 15, TypeScript, and Tailwind CSS 4.
- 🧪 **Quality Assurance** — End-to-end testing via Playwright.

## Quick Start

```bash
# 1. Clone the repository
git clone <repository-url>
cd faaz-dashboard

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser. ✅
